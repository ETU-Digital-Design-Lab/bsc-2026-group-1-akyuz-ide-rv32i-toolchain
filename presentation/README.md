# presentation/

Bu klasör, bitirme projesi sunumu/posteri için ayrılmıştır (örn. `sunum.pptx`/`sunum.pdf`, poster dosyası, demo videosu bağlantısı).

## Mevcut içerik

### `ekran-goruntuleri/` — AkyuzIDE tanıtım ekran görüntüleri

| Dosya | Açıklama |
|---|---|
| `akyuzide_landing_page.jpg` | AkyuzIDE'nin tanıtım/karşılama sayfası (Linux AppImage ve Windows Portable indirme seçenekleri). |
| `kurulum_sihirbazi.jpg` | İlk kurulumda sistem taramasını gösteren kurulum sihirbazı ekranı (Python 3, Icarus Verilog, RISC-V GCC, GTKWave kontrolü). |
| `agent_demo_plan.jpg`, `agent_demo_onay.jpg` | Agent'a "16 LED'li sayaç tasarla ve FPGA karta yükle" görevi verildiğinde üretilen plan ve kullanıcı onayı akışının ekran görüntüleri. |
| `agent_demo_gorev_tamamlandi.png` | Agent'ın aynı görevi (RTL üretimi, simülasyon, bitstream, FPGA'ya yükleme) uçtan uca tamamladığını gösteren ekran. |
| `agent_demo_fpga_secimi.jpeg` | Agent ile FPGA hedef kartı (Basys 3 / Arty A7-35T / Nexys A7-100T) seçimi diyaloğu. |
| `akyuzserver_admin_paneli.jpg` | Uzak Ollama modellerine erişimi yöneten AkyuzServer yönetim panelinin ekran görüntüsü (CPU/RAM/GPU/disk durumu, model yönetimi). |
